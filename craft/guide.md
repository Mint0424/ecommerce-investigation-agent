# 电商经营数据（模拟）

本地只读 MCP 数据源，供电商经营调查工作区使用。所有数据为模拟，固定时点 2026-10-12；日期范围 2026-09-28 至 2026-10-11，币种 CNY。

## 工具

- `list_products`：确认精确 SKU、商品及规格。
- `get_product_rules`：成本、履约费、商品毛利率下限与广告单日预算上限。
- `get_sales`、`get_inventory`、`get_promotions`、`get_advertising`：查询两段相邻等长窗口，返回证据 ID、来源时点、原始行与缺失日期。
- `monitor_sales`：按规则列出销量下降候选；没有后台定时执行。
- `investigate_sku`：固定五工具调查基线，返回结构化报告。非模型推理。
- `review_report`：对完整结构化报告重算，检查证据、状态与行动边界。不证明真实因果，不评价任意自然语言。

## 案例

| SKU | 案例 |
| --- | --- |
| CUP-BLUE-500 | 缺货与销量下降同时出现 |
| CUP-RED-500 | 同商品另一规格，销量稳定 |
| TOWEL-SET-3 | 促销结束与销量下降同时出现 |
| SHOES-WHITE-42 | 广告点击转化率下降 |
| BAG-BLACK | 库存日期缺失，需补查 |
| LAMP-WARM | 最近广告数据未到齐，需补查 |
| BOTTLE-GREEN | 全天不可售却有销量，数据冲突 |
| CABLE-USB-C | 恢复促销会违反商品毛利下限 |

默认最近窗口 2026-10-05 至 2026-10-11，基期 2026-09-28 至 2026-10-04。可以使用 `endDate`、`days` 参数调整；超出完整数据范围时标明缺失。禁止合并规格、将缺失值按零计算或把时间上的相关性当成已证实因果。

演示广告口径：按已支付订单日期、精确 SKU 归因，广告订单与收入是同日商品总量的子集；不含跨日点击归因、退款和未支付订单。实际平台若采用跨日归因，必须先建立可比较口径，不能直接套用本演示的冲突校验。

## 边界

无认证、无外部网络、无店铺写入权限，不包含改价、补货、调预算或删除工具。只能形成待人工审批的经营建议。
